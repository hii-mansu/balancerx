# BalancerX Website

Official React + Tailwind CSS landing page and interactive documentation for BalancerX HTTP Load Balancer.

## Tech Stack

- **Framework**: React.js 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production distribution
npm run build
```
